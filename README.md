# 🧮 Python GUI Calculator

A simple and user-friendly **GUI Calculator built using Python and Tkinter**.

This project performs basic arithmetic calculations through an interactive graphical interface and also supports keyboard input.

## 📌 Project Overview

This Python Calculator is designed as a beginner-friendly desktop application.

It provides a clean calculator interface where users can perform mathematical operations such as:

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`
- Percentage `%`
- Decimal calculations
- Parentheses
- Clear operation
- Backspace
- Keyboard input

The calculator also includes error handling for invalid expressions and division by zero.

---

## 🚀 Features

### 🔢 Basic Calculations
Perform common mathematical operations:

" + "

" - "

" * "

" / "

" % "

### 🧹 Clear Button

The `C` button clears the complete expression and resets the display.

### ⌫ Backspace

The backspace button removes the last entered character.

### 📊 Percentage

The `%` button allows percentage calculations.

### ⌨️ Keyboard Support

The calculator supports keyboard input for:

- Numbers
- Arithmetic operators
- Parentheses
- Enter/Return
- Backspace
- Escape

### ⚠️ Error Handling

The application handles:

- Division by zero
- Invalid mathematical expressions

and displays an appropriate error message.

💻 Requirements
---------------

Python 3.x is required.

Tkinter is generally included with standard Python installations.

▶️ How to Run
-------------

### 1\. Clone the Repository

git clone https://github.com/AvadheshKumarRathaur/Python-GUI-Calculator.git   `

### 2\. Open the Project Folder

`   cd Python-GUI-Calculator   `

### 3\. Run the Calculator

`   python calculator.py   `

The calculator window will open.

🖥️ How to Use
--------------

1.  Enter numbers using the calculator buttons or keyboard.
    
2.  Select an arithmetic operator.
    
3.  Enter the second number.
    
4.  Press = or the **Enter** key.
    
5.  The result will be displayed.
    

### Example
`   10 + 20   `

**Output:**

`   30   `
